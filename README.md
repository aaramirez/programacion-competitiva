# Programación competitiva

Preparación para el ICPC, las olimpiadas de informática y los concursos en línea como Codeforces y AtCoder: cómo reconocer cada familia de problemas en el enunciado, la técnica que lo resuelve, la plantilla de código, los errores bajo presión y la estrategia de un equipo contra el reloj.

**Ver en línea:** https://aaramirez.github.io/programacion-competitiva/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
